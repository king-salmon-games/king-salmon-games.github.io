# King Salmon Games website

Static studio website for [kingsalmongames.com](https://kingsalmongames.com), hosted with GitHub Pages. The homepage introduces WUMBOS, Cream Cheese × Phone, PocketLink, and Nemus Obscurum.

## Local preview

Run a static HTTP server from this directory, then open the printed local address:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Open <http://127.0.0.1:4173/>. The site uses plain HTML, CSS, and dependency-free JavaScript with no build step, analytics, cookies, or form backend.

## Content

- `index.html`: studio introduction, four-game lineup, studio information, and contact.
- `wumbos.html`: the existing WUMBOS feature overview and playtesting contact.
- `support.html`: support for the studio's games, including clearly identified WUMBOS-specific instructions.
- `privacy.html`: the existing website and WUMBOS privacy notice. Its WUMBOS data-handling statements do not describe the other games.
- `styles.css`: shared responsive styles for the homepage, game details, and utility pages.
- `experience.js`: homepage world selection, fragment navigation, motion controls, and the animated current.
- `assets/`: locally hosted artwork and studio branding.

Keep game descriptions grounded in the corresponding project. Add store or public playtest buttons only after their destinations are verified; email inquiries use the studio's existing contact address. When adding a page, update its canonical URL and `sitemap.xml`. Update the stylesheet version in each HTML file when changing shared styles.

## Homepage interaction

The homepage opens with a procedural current drawn on a 2D canvas. A locally authored SVG preserves the composition without JavaScript or canvas support. Animation respects reduced-motion preferences, can be paused with the visible motion control, and stops while offscreen or in a hidden tab. Smaller screens use fewer points and a lower frame rate. Motion choices are kept only in the current page session.

The four game links progressively become keyboard-accessible tabs. Use Left/Right or Home/End to select a world; the “Next” control also cycles through them. Clicks and the Next control add browser-history entries, while arrow-key selection replaces the current entry. Project artwork starts loading as the selector approaches the viewport, without blocking navigation. Each project keeps its URL fragment, including the legacy WUMBOS fragments. Without JavaScript, all four stories remain visible with ordinary anchor navigation.

## Artwork sources

The game imagery reuses artwork and development captures from the studio's source repositories. The copied opaque PNGs were encoded as JPEG at quality 86, preserving their dimensions and reducing the delivery files by about 80%. The transparent Cream Cheese × Phone wordmark remains PNG.

| --- | --- |

| `creamcheese-wordmark.png` | `creamcheese`: `game/Assets/Resources/Art/TitleWordmark.png` |
| `creamcheese-gameplay.jpg` | `creamcheese`: `artifacts/campaign-qa/puzzle-area-1-390x844-normal-view-1.png` |

Existing WUMBOS artwork and the crowned-salmon branding are retained. The site labels development captures and promotional artwork separately.

`assets/current-field.svg` is original procedural line artwork for the homepage, with no external assets or embedded scripts. Its animated counterpart is generated by `experience.js`.
